# 美股资本市场专业评测 v0.1.0

这是独立的美股场景包，不修改 AI World OS 的业务语义。OS 只负责运行、工具调用、证据记录、动作提交、结算插件加载和归档；美股市场规则全部声明在本场景包内。

## 角色

- `investor_a` Chen Wen：价值型美股基金经理，关注估值、自由现金流、安全边际和股东回报。
- `investor_b` Lin Feng：成长型美股基金经理，关注财报催化、产品周期、行业景气、期权和市场定价。

## 世界模型

- 市场：NYSE / NASDAQ / AMEX 股票与 ETF。
- 代码：统一使用 `.US` 后缀，例如 `AAPL.US`、`MSFT.US`、`NVDA.US`、`SPY.US`。
- 账本：模拟成交，USD 记账，初始现金 10,000。
- 基准：SPY，主指标为风险调整后超额收益。
- 交易窗口：纽约时间周一至周五 09:30-16:00；盘前阶段只能研究和更新计划，不能成交。
- 工具：场景声明美股研究工具；行情与期权由只读 `longport` 连接器提供，
  财务、公告、重大事件、财报日历和宏观由 `us_market_research` 对
  SEC EDGAR、Nasdaq 与 FRED 做参数化适配。Agent 不再自行拼接数据源 URL。

## 策略纪律

- 首次建仓前必须获得实时行情与至少两类非行情研究证据。
- 建仓前先提交 `update_investment_plan`，下一拍才可 `buy_asset`。
- 价值型必须有财务报表，并补估值或 SEC 披露证据。
- 成长型必须有新闻、SEC、财报或产品催化，并补财报预期、行业或期权证据。
- 买卖单必须带 `asset_id`、`asset_name`、`quantity`、`expected_price`，有行情证据时带 `price_evidence_ref`。

## 场景边界

本场景仅用于模拟与模型评测，不连接真实券商，不构成现实投资建议。
